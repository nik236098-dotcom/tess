# Покер с друзьями — Telegram Mini App

Техасский холдем **на игровые фишки**. Никаких денег, депозитов и казино: комната
создаётся по коду, друзья заходят по ссылке из Telegram и играют вечером в своё удовольствие.

<!-- Скриншоты стола удобно снять самому: откройте приложение в Telegram Desktop. -->

## Что умеет

- Безлимитный техасский холдем на 2–9 мест, приватные столы с кодом из пяти символов.
- Настройка блайндов, стартового стека, числа мест и времени на ход.
- Правильная торговля: блайнды, минимальные рейзы, короткие олл-ины, **сайд-поты**,
  дележ банка при равных руках и возврат непокрытых ставок.
- Таймер хода: кто не успел — автоматический чек или пас, стол не стоит.
- Возврат за свой стек после обрыва связи, автопропуск раздач для отключившихся.
- Пополнение стека, когда фишки закончились, — это же игра ради интереса.
- История раздач и чат за столом.
- Тема подхватывается из Telegram, интерфейс рассчитан на телефон.
- Ноль внешних зависимостей: только Node.js (WebSocket-сервер написан вручную).

## Быстрый старт локально

```bash
npm start          # сервер на http://localhost:3000
npm test           # 24 теста: движок, комбинации, подпись Telegram, протокол
```

Без `TELEGRAM_BOT_TOKEN` сервер поднимается в **режиме отладки**: можно открыть
`http://localhost:3000` в обычном браузере, представиться именем и играть.
Чтобы проверить игру вдвоём, откройте вторую вкладку в приватном окне.

## Публикация как Mini App

Telegram открывает мини-аппы только по HTTPS, поэтому нужен домен с сертификатом.

### 1. Бот и приложение в @BotFather

1. `/newbot` — получите токен.
2. `/newapp` — выберите бота, задайте название, описание, картинку 640×360
   и **короткое имя** (например `poker`), а в поле Web App URL укажите адрес вашего сервера.
3. Запомните имя бота и короткое имя приложения — из них собирается ссылка
   `https://t.me/<бот>/<приложение>`.

### 2. Переменные окружения

```bash
export TELEGRAM_BOT_TOKEN=123456:ABC...      # обязательно: по нему проверяется подпись initData
export TELEGRAM_BOT_USERNAME=my_poker_bot    # для кнопки «позвать друзей»
export TELEGRAM_APP_SHORT_NAME=poker
export PORT=3000
node server/index.js
```

Образец лежит в `.env.example`.

### 3. HTTPS

Любой привычный способ, например nginx перед приложением:

```nginx
server {
    listen 443 ssl;
    server_name poker.example.com;

    # сертификат от certbot

    location / {
        proxy_pass http://127.0.0.1:3000;
        proxy_http_version 1.1;
        proxy_set_header Upgrade $http_upgrade;      # обязательно для WebSocket
        proxy_set_header Connection "upgrade";
        proxy_set_header Host $host;
        proxy_read_timeout 3600s;
    }
}
```

Или в контейнере:

```bash
docker build -t poker-friends .
docker run -d -p 3000:3000 -e TELEGRAM_BOT_TOKEN=... poker-friends
```

Для разовых посиделок хватит и туннеля (`cloudflared tunnel --url http://localhost:3000`):
полученный HTTPS-адрес вставьте в настройки приложения у @BotFather.

## Как играют

1. Один человек открывает приложение и жмёт **Создать стол**.
2. Кнопка **＋** в шапке отправляет друзьям ссылку, по которой они попадают сразу за нужный стол
   (можно просто продиктовать код из пяти символов).
3. Все садятся на свободные места, хозяин стола нажимает **Начать игру**.
4. Раздачи идут одна за другой, пока хозяин не поставит паузу.

Ссылка вида `https://t.me/<бот>/<приложение>?startapp=КОД` открывает приложение
и сразу заводит гостя в нужную комнату.

## Устройство проекта

```
server/
  index.js          HTTP, статика, маршрутизация команд по WebSocket
  wsserver.js       свой минимальный WebSocket (RFC 6455)
  telegram.js       проверка подписи initData
  room.js           стол: места, стеки, таймеры, состояние для клиента
  poker/
    cards.js        колода и тасование
    evaluator.js    оценка комбинаций, лучшие 5 из 7
    hand.js         одна раздача: торговля, банки, вскрытие
public/             мини-апп: index.html, styles.css, app.js
test/               тесты движка, комбинаций, подписи и протокола
```

Игровая логика живёт **только на сервере**: клиент присылает намерения и рисует
присланное состояние. Чужие карты до вскрытия просто не покидают сервер, поэтому
подсмотреть их в браузере нельзя.

## Ограничения

- Состояние хранится в памяти: перезапуск сервера обнуляет столы.
- Пустая комната живёт полчаса, потом удаляется.
- Одно активное подключение на игрока — вторая вкладка вытесняет первую.
