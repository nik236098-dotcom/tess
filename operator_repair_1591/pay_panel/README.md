# Панель оплат eSIM (pay_panel)

Один бот с ролями: **админ** (ты, по Telegram ID) и **оплатчики** (по инвайту). Оплатчики по очереди
оплачивают ссылки своими картами, получают ставку в $ за успех. Движок оплаты (карта → 3DS → YooMoney →
status) переиспользуется из `pay_bot.py`. Полное ТЗ — в `SPEC.md`.

Это **единственный** бот платежей — старый pay_bot больше как отдельный бот не нужен (его код — движок).

## Установка

Возьми токен нынешнего pay_bot (новый бот создавать не надо) и останови старую службу:
```
sudo systemctl disable --now pay_bot
curl -fsSL https://raw.githubusercontent.com/nik236098-dotcom/tess/codex/operator-observer-15.87/operator_repair_1591/pay_panel/install_pay_panel | sudo bash
```
Спросит: токен, твой Telegram ID (узнать — @userinfobot), контакт поддержки, прокси Telegram, ключ DeepSeek.
Ставит pay_panel.py + pay_bot.py (движок), venv+Chromium, службу `pay_panel`.

После установки напиши боту `/start` с админского аккаунта.

## Роли и вход
- **Админ** — по `admin_id` из конфига. Видит админ-меню, может сам встать в очередь и платить.
- **Оплатчик** — входит по одноразовому коду (`/invite <код>` создаёт его). Видит панель оплатчика.
- **Забанен** — `/ban @тег|ID причина`, снять — `/unban @тег|ID`.

## Как идёт работа
1. Админ: «📤 Загрузить ссылки» → пачка ссылок в очередь. «🟢 Включить приём».
2. Оплатчик (или админ): «▶️ Встать в очередь». Очередь строго по одному.
3. Чья очередь — тому «🟢 Твоя очередь, пришли карту НОМЕР СРОК КОД».
4. Бот открывает ссылку, вводит карту, проходит 3DS (кнопка «📨 Повтор СМС») / YooMoney-PUSH,
   читает итог из URL (`status=success/fail`).
5. Успех → +ставка, лимит карты (3 успеха глобально по номеру), «💳 Брать карту дальше».
   Отказ → кнопки «та же / новая карта» + предупреждения. Незнакомый банк → ИИ-агент (по описанию
   оператора вводит код), либо другая карта. Сайт недоступен / заказ не найден → ссылка не теряется.
6. «🚪 Закончить работу» или 3 мин без ответа — очередь уходит дальше.

## Команды админа
- `/invite <код>` — одноразовый код доступа.
- `/ban @тег|ID причина` · `/unban @тег|ID`
- `/backup` — прислать бэкап базы (деньги!).

## Канал логов
Добавь бота в канал **админом** → Настройки → «Выбрать канал логов» → выбери из списка. Туда идут
финальные оплаты (скрин+ссылка+кто) с кнопкой «🚫 Отмена оплаты» (возврат ставки с баланса, −1 к карте).

## Выплаты
Оплатчик «💸 Запросить выплату» — весь баланс замораживается, тебе приходит запрос с ✅/🚫.
«Выплачено» списывает заморозку; «Заблокировать» возвращает баланс оператору. Выплату (крипта) делаешь сам.

## Безопасность / надёжность
- Карты в памяти процесса, в лог идёт только маска ****1234.
- Перезапуск бота: ссылки «в работе» возвращаются в очередь.
- Серия мгновенных сбоев Билайна → авто-пауза приёма + пуш тебе (похоже на бан IP).
- База бэкапится ежедневно и по `/backup` (папка `backups/`, последние 10).
