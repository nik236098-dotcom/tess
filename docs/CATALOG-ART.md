# Catalog artwork

Built-in imagegen, two atlas assets. Final files:
- `public/img/catalog/objects.webp`: 4×4 transparent object atlas, 1254×1254.
- `public/img/catalog/environments.webp`: 2×2 environment atlas, 1254×1254.

The generated PNGs were encoded to WebP at quality 87 without resizing, cropping or changing their composition. CSS selects atlas cells. Existing project cards and lounge textures remain the visual references.
