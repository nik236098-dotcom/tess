# Каталог мини-игр

После переработки осталось 16 новых игр; существующая баккара не дублируется. Кейсы, коллекция символов и скретч-карты удалены из каталога и недоступны для новых ставок. Ставки новых игр: $1–$1000. Правила и таблицы доступны внутри каждой игры. Выплата включает ставку, денежные расчёты ведутся в центах.

## Правила и источники

Это набор классических правил, адаптаций и авторских случайных игр, а не точная копия всего каталога Stake.

| Игры | Основа |

| Andar Bahar | Первая сторона Andar, одна колода; выплаты 1.9×/2×. [Варианты правил](https://wizardofodds.com/games/andar-bahar/) |

| Орёл или решка, Камень · ножницы · бумага | Независимые равновероятные исходы, серия побед и возможность забрать; механика Flip/RPS |

Для адаптаций алгоритмы случайных событий сверены с [описанием Stake](https://stake.com/provably-fair/game-events). Это не означает использование их серверов, сертификации или системы проверки seed. Здесь используется серверный криптографический генератор Node.js.

Пинбол, пенальти, дартс и рыбалка — случайные игры: точность или скорость нажатия не меняет вероятность. Клиентская анимация показывает уже рассчитанный сервером исход.

## Надёжность и интерфейс

- Раунд и баланс сохраняются вместе; ошибка записи отменяет изменение.
- Повторное действие со старой ревизией отклоняется. Завершённый раунд оплачивается один раз.
- Неоткрытые карты, будущие опасные шаги и скрытый приз билета не передаются клиенту.
- Общие правила используются клиентом и сервером. Настройки и ставка блокируются во время активного раунда.
- Область сцены отделена от кнопок; сетки используют сжимаемые колонки. Элементы управления не размещаются поверх соседнего блока.
- Проверены серверные сценарии всех 16 игр, денежный учёт, восстановление, математические распределения и обработчики нажатий. DOM-тесты не заменяют проверку геометрии в настоящем браузере: визуальная проверка на iPhone не выполнена.

## Установка

В терминале сервера:

```bash
cd /opt/poker/app && sudo -u poker git fetch origin codex/crash && sudo -u poker git show FETCH_HEAD:scripts/crash-update.sh | sudo bash
```

Скрипт проверяет синтаксис и перезапускает службу poker. Публикация ветки GitHub сама по себе не запускает обновление сервера.


## Переработка графики и анимаций

Вместо плоских SVG-иллюстраций используются сгенерированные объёмные объекты, фактурные фоны и колода проекта. Изображения хранятся в `public/img/catalog/objects.webp` и `public/img/catalog/environments.webp`, загружаются с того же сервера (вместе около 670 КиБ). Исходная колода — `public/img/croc-test/deck.webp`.

| Игра | Анимация |
| --- | --- |
| Diamonds | Пять объёмных кристаллов последовательно опускаются на бархатный подиум |
| Видеопокер | Переворот и раздача каждой карты; сохранённые карты неподвижны |
| Limbo | Плавный рост числа и полёт ракеты; число не перемещается вместе с ракетой |
| Sic Bo | Бросок трёх объёмных кубиков с разным моментом остановки |
| Chicken | Шаг с подскоком и проезд машины; отдельное состояние столкновения |
| Орёл / решка | Двусторонняя монета, замедление вращения и тень |
| Камень / ножницы / бумага | Три подготовительных движения и синхронное раскрытие жестов |
| Croc Slots | Три непрерывных ленты символов с последовательным торможением |
| Andar Bahar | Полёт каждой карты к своей стороне в порядке серверной колоды |
| Пенальти | Полёт мяча с уменьшением по перспективе и движение перчаток вратаря |
| Дартс | Подлёт дротика к рассчитанной точке мишени |
| Боулинг | Прокат шара, столкновение, последовательное падение нужных кеглей |
| Воздушный шар | Движение насоса, увеличение шара, частицы при разрыве |
| Гонки | Четыре машины на ночной трассе, промежуточные движения, серверный порядок финиша |
| Пинбол | Лопатки, отскок от поверхности бампера и возвращение либо падение в слив |
| Рыбалка | Опускание лески, приближение рыбы и подъём улова |

Таймлайны находятся в `public/casino-motion.js`; они не определяют результат и не изменяют баланс. Позиции обновляются через requestAnimationFrame. Уход с экрана отменяет текущий таймлайн. При reduced motion сразу показывается конечное состояние. Поле имеет постоянную высоту; кнопки расположены отдельным блоком в обычном потоке документа.

При следующем входе в аккаунт ставка незавершённых удалённых игр возвращается. Уже рассчитанная, но ещё не зачисленная выплата сохраняется в полном размере. Возврат и отметка завершения пишутся одной операцией; повторный вход не даёт повторного возврата. Если баланс достиг системного предела, запись остаётся ожидающей до освобождения места и следующего входа.

Графика создана встроенным imagegen; экспорт WebP сохраняет геометрию и прозрачность. Промпты зафиксированы в `docs/CATALOG-ART.md`. Визуальная проверка в реальном Telegram/iPhone не выполнена.
