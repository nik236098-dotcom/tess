# Amethyst: покер и тестовые боты

Новый экран включён по умолчанию для холдема и омахи. Кнопка «Прежний дизайн» под столом мгновенно возвращает предыдущую тему на этом устройстве. Настройки лобби и других игр не меняются.

## Игра

Четыре действия: Fold, Call/Check, Raise и All-in. Raise открывает панель и не делает ставку. В панели доступны ½ банка, банк, 2× банк, ползунок и ручной ввод с точкой или запятой. Сумма — **рейз до**, включая уже поставленное. Пресеты считаются от банка после колла и ограничиваются допустимым диапазоном. Подтверждение показывает точную итоговую ставку. Отмена ничего не отправляет. Панель закрывается при смене хода/раздачи. All-in недоступен, когда правила разрешают только частичный колл или не открывают повторный рейз.

## Боты

Администратор нажимает свободное место → «Посадить бота». Можно выбрать стек. Имя и отдельная аватарка явно показывают, что это бот. Нажатие на него открывает удаление. Во время раздачи бот пасует, оставшийся стек возвращается после расчёта банка.

Права проверяются сервером через существующие TELEGRAM_ADMIN_IDS. Обычный игрок не может добавлять/удалять ботов, даже отправив команды вручную. Стек списывается с баланса создавшего бота администратора. Не создаются аккаунты ботов с бесплатным стартовым балансом. После выхода владельца боты убираются; при обрыве связи есть пять секунд на переподключение. Без сидящего подключённого человека новые раздачи ботов не начинаются.

Это усиленный тренировочный соперник, **не подтверждённый профессиональный/GTO-бот**. Он использует Монте-Карло для оценки equity, взвешивает стартовые диапазоны по публичным действиям, учитывает позицию, pot odds, число соперников, эффективные стеки, value-bet и редкие полублефы. Для омахи оценщик использует ровно две карманные и три общие карты. Ограниченный бюджет расчёта и эвристики не гарантируют профессиональную силу; для её оценки нужен отдельный матчевый бенчмарк на большой выборке.

Worker получает только специально отобранные поля: свои карты, борд, публичные стеки/ставки/действия. Чужие карты и колода не передаются. Общий пул ограничен двумя потоками и 64 ожидающими заданиями. Расчёт ограничен по времени; устаревшие ответы отменяются. При сбое — законный чек или пас, чтобы стол продолжал играть.

## Проверка

`npm test` включает движок, работу через настоящий WebSocket, запрет команд неадмину, сохранность фишек, устаревшие решения бота и реальный worker. `node test/visual/prepare-amethyst.js` создаёт временные страницы QA из **текущих** index.html/app.js для мобильной проверки заполненного стола; они не входят в поставку. Прототипные портреты в QA взяты из утверждённого макета. В игре используются аватары Telegram, а для ботов — отдельные изображения роботов.

## Установка и возврат

Сначала получить ветку `codex/amethyst-poker-bots`. Скрипт `scripts/poker-update.sh install` рассчитан на `/opt/poker/app`, пользователя `poker` и службу `poker`. Он сохраняет первую предыдущую версию в `backup/pre-amethyst`, останавливает службу, переключает код и запускает её. Если запуск сразу завершился ошибкой, возвращает предыдущий commit. При незакоммиченных изменениях кода останавливается до изменения файлов. Игровые балансы и файлы окружения не сбрасываются.

Для полного возврата после установки: `sudo bash /opt/poker/app/scripts/poker-update.sh rollback`. Это вернёт исходный commit, в том числе прежние кнопки и сервер. Для возврата только внешнего вида достаточно кнопки под столом.
