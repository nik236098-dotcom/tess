# Crash — одиночный режим

Новая игра в разделе «Игры»: фиолетовый график, история 20 результатов, ставка, ручное получение, автостоп с полем и пресетами, анимация выигрыша в стиле Mines.

## Правила
Раунд начинается сразу после ставки. Коэффициент растёт от 1.00× экспоненциально. Ставка от $0.10 до $100000. Автостоп от 1.01× до 1000000× фиксируется до начала раунда. При достижении автостопа начисляется ставка × коэффициент с округлением вниз до цента. Если краш наступает раньше — ставка проиграна. При равенстве порога и точки краша автостоп выигрывает. Ручное получение проверяется по времени получения команды сервером; при достижении точки краша оно уже опоздало. На пределе 1000000× происходит автоматическое получение.

Модель вдохновлена правилами Stake Crash, адаптирована для одиночного раунда. Это собственная реализация, не код Stake. Криптографический равномерный случайный U преобразуется в floor(0.99 / U × 100) / 100, с границами 1 и 1000000. Возможен мгновенный краш 1.00×. Теоретический возврат для фиксированного автостопа около 99% до округления выплаты. Проверка server/client seed (provably fair) не реализована.

## Надёжность
Скрытая точка краша не передаётся клиенту. Ставка, результат и баланс сохраняются вместе в accounts JSON. Обрыв соединения не останавливает раунд; автостоп действует и без клиента. После перезапуска исходные сроки событий восстанавливаются. Повторная команда не списывает и не начисляет средства дважды. При превышении лимита кошелька выплата остаётся ожидающей, следующий раунд блокируется до зачисления.

## Установка
```bash
cd /opt/poker/app && sudo -u poker git fetch origin codex/crash && sudo -u poker git show FETCH_HEAD:scripts/crash-update.sh | sudo bash
```
Скрипт не перезаписывает незакоммиченные изменения отслеживаемых файлов. При ошибке запуска автоматически возвращает предыдущий коммит.

## Проверки
Тесты движка, списаний и выплат, восстановления и реального обмена WebSocket. Синтаксическая проверка клиентских и серверных JS. Визуальная проверка в браузере здесь недоступна: локальный адрес заблокирован средой; отображение на iPhone необходимо проверить после установки.
