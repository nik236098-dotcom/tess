# Общий стандарт игр

Согласован 9 сентября 2026. Рулетка исключена из текущего внедрения. Mines и Nvuti полностью сохраняют прежний интерфейс, размеры, ставки и отображение результата.

## Оформление

- Панели: индиго `#141636 → #0E102A`, лавандовая рамка, верхний блик.
- Основное действие: `#8D7FF8 → #6A5AE8 → #5A4BE0`, белый текст.
- Получение выплаты: `#5FF26A → #2BCF45 → #1FAE36`, текст `#06200D`.
- Основная кнопка 52 px, скругление 16 px. Поле суммы и ½ / 2× / Max — 46 px, скругление 12 px.
- Подпись «Сумма ставки» над полем. Порядок панели: игровые настройки, действие, подпись, сумма и модификаторы.
- Отдельные необходимые действия (следующий шаг, насос) сохраняются; одинаковое действие не дублируется.
- Выбор стороны монеты во время раунда запускает бросок из нижней панели. Основная кнопка получает выплату.

## Экран

Шапка учитывает системные отступы Telegram. Нижняя панель сохраняет размеры кнопок; сцена занимает оставшееся пространство. Масштабируется только сцена, не весь экран. При клавиатуре или очень низком горизонтальном экране прокрутка оставляет управление доступным.

Последовательность коэффициентов располагается над панелью; текущий шаг выделяется и остаётся видимым. Повторяющиеся карточки коэффициента и выплаты удалены из видимой компоновки. Коэффициенты лунок Plinko остаются на поле; второй таблицы под количеством шариков нет. История Hilo находится внутри поля вместо статистики.

Карточные столы сохраняют свои фишки и действия раздачи. Результат показывается поверх экрана в общей плашке нормального размера; он не встраивается между картами. Места игроков покера не меняются.

## Итог раунда

`public/game-result.js` классифицирует целые суммы в центах. Серверный флаг «win» сам по себе не определяет цвет:

| Выплата относительно всей ставки | Заголовок | Акцент |
| --- | --- | --- |
| Больше | Выигрыш | `#5CFF6A` |
| Равна | Возврат ставки | `#C9C1E5` |
| Меньше, но положительная | Частичный возврат | `#CF8797` |
| Нулевая | Проигрыш | `#FF6B7A` |

Nvuti исключена из всего общего редизайна: восстановлены исходная компоновка, стили, порядок настройки ставки и собственное отображение результата.

Плашка появляется поверх экрана по центру, вне потока игрового поля. Она не уменьшает сцену, не занимает место в панели и не перемещает кнопки.

Плашка 240 × 120 CSS px, скругление 16 px: три видимые строки — заголовок 16 px, сумма 28 px, итоговый коэффициент 13 px. Для длинных сумм шрифт уменьшается. Пояснение сохраняется только для экранного диктора. Отдельной подписи «Выплата» нет. Перед выплатой нет плюса: она включает исходную ставку. Полный проигрыш всегда 0×, даже если до него был достигнут другой коэффициент.

Итог появляется после анимации и подтверждения выплаты. Удачный промежуточный шаг обновляет поле и кнопку получения. Ничья, сохраняющая серию, не завершает раунд. Для группы Plinko и перекрывающихся бросков дартса итог считается по всем завершённым ставкам группы; история отдельных попаданий сохраняется. Для нескольких рук и покерных банков учитывается итог всего раунда для конкретного участника.

Плашка закрывается и не появляется повторно при обычной перерисовке того же результата. Следующая игра сбрасывает закрытие. Кнопки «Играть ещё» внутри нет. Дополнительные звуки не добавляются.

Общие стили находятся в `public/game-standard.css`; адаптация сцены — в `public/game-layout.js`. Изменения правил, вероятностей и расчёта выплат в этот стандарт не входят.

Баккара: исходные оформление, фон, кнопки и фишки; сохраняются смещение вниз под системную область и полноэкранная плашка результата. Общая плашка результата во всех использующих её играх поднята на 40 CSS px относительно центра доступной области экрана. Исключения сохраняются: Mines и Nvuti используют исходное отображение, рулетка не меняется.
